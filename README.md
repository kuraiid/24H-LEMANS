# 24h Le mans

Сайт для гонки «24 часа Ле-Мана» и чемпионата WEC. Информация о командах, пилотах, трассе, бронирование билетов.

---

## Технологии

- HTML5, CSS3 (SCSS)
- JavaScript
---

## Установка и запуск
Если есть впн, можно попробовать посомтреть сайт загружанный уже  на сервер - https://24h-lemans.tllswiti.workers.dev/
### 1. Клонировать репозиторий
```
git clone https://github.com/kuraiid/24H-LEMANS.git
cd lm24-wheel
```

### 2. Запустить локальный сервер - ОБЯЗАТЕЛЬНО (без него не будут работать два компонента)

Если OpenServer: поместить папку проекта в `domains/`.

Если встроенный сервер PHP:

php -S localhost:8000

Открыть в браузере: `http://localhost:8000`

## Структура проекта
```
├── src/
│   ├── scss/            # Исходники стилей (SCSS)
│   │   ├── settings/    # Переменные, курсор, сброс стиелй
│   │   ├── tools/       # Миксины, шаблоны
│   │   ├── typeface/    # Типографика, шрифты
│   │   ├── repeatBlock/ # Шапка, футер, контейнер, фоновые линии - повторяющиеся блоки
│   │   ├── components/  # Кнопки, карточки - повторяющиеся объекьы
│   │   ├── pages/       # Уникальные стили страниц
│   │   └── style.scss   # Подключение всех других стилей
│   └── js/              # JavaScript
│   └── image/           # Изображения, иконки, SVG
│   └── fonts/           # Хранятся шрфиты
│   └── css/             # Скомпелированный css файл
├── index.html           # Главная страница
├── history.html         # История
├── teams.html           # Команды
├── track.html           # Трасса
├── tickets.html         # Бронирование
└── README.md

```
