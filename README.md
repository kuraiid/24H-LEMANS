# 24h Le mans

Сайт для гонки «24 часа Ле-Мана» и чемпионата WEC. Информация о командах, пилотах, трассе, бронирование билетов.

---

## Технологии

- HTML5, CSS3 (SCSS)
- JavaScript
---

## Установка и запуск

### 1. Клонировать репозиторий

git clone https://github.com/kuraiid/24H-LEMANS.git
cd lm24-wheel


### 2. Запустить локальный сервер

Если OpenServer: поместить папку проекта в `domains/`.

Если встроенный сервер PHP:

php -S localhost:8000

Открыть в браузере: `http://localhost:8000`
